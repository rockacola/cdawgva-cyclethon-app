# 2026-05-22

## What I worked on

Added `npm run snapshot` — a Playwright Node script (`scripts/snapshot.js`) that visits every route, takes a full-page screenshot at 1280px wide, and archives results to `snapshots/2026-05-22_0750/`.

## Decisions made

- **Cypress dropped for snapshots.** Started with a Cypress spec but `cypress-image-diff-js` hooks `after:screenshot` globally and moves every screenshot file to its own comparison folder, making clean snapshot capture impossible without fighting the plugin. Playwright is a standalone Node script with no interference.
- **Footer bottom as height anchor, not `scrollHeight`.** `scrollHeight` inflates when `min-height: 100vh` is recalculated after viewport resize. Measuring `footer.getBoundingClientRect().bottom` gives the actual rendered end of content. Two resize passes let `vh`-unit elements settle before the final screenshot.
- **Per-route `setup` hook for `/ja`.** The route sets `locale` in localStorage and redirects to `/`. Instead, we set `localStorage.locale = '"JA"'` (JSON-serialised, as `use-local-storage-state` expects) before navigating to `/` directly.
- **`networkidle` wait with 5s timeout.** Helps lazy assets like Google Maps load; timeout prevents SSE routes (e.g. `/donations/live`) from hanging forever.
- **Next.js dev overlay hidden** via `document.querySelector('nextjs-portal').style.display = 'none'` before capture.
- **Timestamp format:** `2026-05-22_0750` (local time, no ISO `T`, no colon separators).
- **Folder named `snapshots/`**, gitignored — intended for manual archiving to cold storage.

## Problems / friction

- `cypress-image-diff-js` silently reroutes all `cy.screenshot()` calls; took a while to trace via the `after:screenshot` plugin hook.
- Playwright's `fullPage: true` produced trailing whitespace; `scrollHeight`-based viewport resize made it worse due to `min-height: 100vh` re-inflation. Settled on two-pass footer-bottom measurement.
